# Changelog

## API 1 — 2026-10-25

- Folder-based Lua 5.4 mod loader in the custom Windows PC game.
- Dev Tools Mods tab: installation folder, reload, active/error status.
- Namespaced host-only commands and load/unload/tick/player/chat/block notifications.
- Player snapshots, main inventory reads, item queries, give/take/heal/flight/teleport/chat.
- Loaded-block reads/writes, per-dimension time and weather.
- Private persistent mod data, bounded VM resources, isolated failures, rotating logs.
- Three example mods, manifest schema, editor snippets, installation and API documentation.
